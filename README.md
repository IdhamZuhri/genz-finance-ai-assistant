# 💰 GenZ Finance Bot  
### AI Budget Assistant

## 📌 Overview
GenZ Finance Bot is a web-based AI assistant designed to help users manage their personal finances through conversational interaction.

The system analyzes income, expenses, and spending behavior to generate **personalized financial insights and budgeting recommendations**.

---

## 🚀 Features

- 💬 Conversational AI interface for financial queries  
- 📊 Budget analysis based on user input  
- 📈 Personalized spending insights  
- 🧠 Smart recommendations for better financial decisions  

---

## 🧠 Problem Statement
Many young adults struggle with:
- Tracking expenses consistently  
- Understanding spending habits  
- Making informed financial decisions  

---

## 💡 Solution
GenZ Finance Bot provides:
- An interactive chatbot experience for finance tracking  
- Automated analysis of income and expenses  
- Simple, actionable financial guidance  

---

## 🛠️ Tech Stack

- **Frontend:** HTML / CSS / JavaScript  
- **Backend:** Node.js / Flask 
- **AI Logic:** Rule-based / API-based
